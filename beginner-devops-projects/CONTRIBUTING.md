# Contributing

This is a learning project, so contributions are welcome but kept simple.

1. Fork the repo and create a branch for your change.
2. Run the tests before opening a pull request:
   ```bash
   pip install -r requirements.txt
   pytest -q
   ```
3. Keep pull requests small and focused on one change.
4. Describe what you changed and why in the pull request description.

If you're using this project to learn, feel free to open issues for anything
that's confusing or broken — that's useful feedback too.
