# Learning Roadmap

## Phase 1 — Linux + Git
- SSH into a Linux server
- Learn processes, ports, permissions and logs
- Create branches and pull requests

## Phase 2 — Docker
- Build the image
- Run it directly
- Understand layers, volumes and networks

## Phase 3 — Compose + Nginx
- Start the full stack
- Understand service discovery
- Configure the reverse proxy

## Phase 4 — CI/CD
- Push to GitHub
- Observe GitHub Actions
- Add linting and more tests

## Phase 5 — Cloud + Terraform
- Provision EC2
- Install Docker
- Deploy the stack
- Destroy resources when finished

## Phase 6 — Kubernetes
- Learn Pods, Deployments and Services
- Scale replicas
- Add health checks

## Phase 7 — Observability
- Inspect `/metrics`
- Open Prometheus
- Log into Grafana (Prometheus is already connected as a data source) and build a simple dashboard
