# DevOps Complete Starter — 10 Numbered Projects

A beginner DevOps portfolio, broken into 10 small, standalone projects.
Each one builds on the last, adding exactly one new concept, and each has
its own README with instructions and things to understand before moving on.

| # | Project | Adds |
|---|---------|------|
| 1 | [project-01-linux-and-git](project-01-linux-and-git/) | Linux server basics, Git workflow |
| 2 | [project-02-python-app](project-02-python-app/) | A small FastAPI app |
| 3 | [project-03-testing](project-03-testing/) | Automated tests with pytest |
| 4 | [project-04-dockerize](project-04-dockerize/) | Packaging the app into a Docker image |
| 5 | [project-05-compose-and-nginx](project-05-compose-and-nginx/) | Docker Compose + an Nginx reverse proxy |
| 6 | [project-06-ci-github-actions](project-06-ci-github-actions/) | Automated testing & building on every push |
| 7 | [project-07-deploy-workflow](project-07-deploy-workflow/) | A manual deploy workflow template |
| 8 | [project-08-terraform-aws](project-08-terraform-aws/) | Provisioning a real AWS server with Terraform |
| 9 | [project-09-kubernetes](project-09-kubernetes/) | Running the app under Kubernetes |
| 10 | [project-10-monitoring](project-10-monitoring/) | Prometheus + Grafana monitoring |

## How to use this

Go through the projects in order — start with Project 1's README and work
down to Project 10. Each folder is self-contained and runnable on its own,
so you can also jump straight to whichever topic you want to practice.

Project 10 has everything: the full app, Docker, Compose, Nginx, CI, a
deploy workflow, Terraform, Kubernetes, and monitoring all in one place —
treat it as the "finished" version of this series.
