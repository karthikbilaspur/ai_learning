## 🚀 How to Run Any Project

Every project follows the exact same 3 commands:

```bash
cd 01-iris-flower-classifier
pip install -r requirements.txt
python main.py
```

> **Pro Tip:** Open the root folder `beginner-ml-projects` in VSCode and use the Jupyter extension. You can run any `.py` file as interactive cells with `# %%`.

## 🧠 Learning Path - Recommended Order

**If you are starting from zero, do it in this order:**

1.  **01 Iris** - Understand classification
2.  **04 Titanic** - Learn data cleaning
3.  **02 Bangalore House Price** - Understand regression
4.  **08 Diabetes** - Binary classification in healthcare
5.  **07 Customer Segmentation** - Your first unsupervised project
6.  **03 Spam SMS + 06 Movie Sentiment** - Intro to NLP
7.  **05 Handwritten Digit** - Intro to Computer Vision
8.  **10 Cats vs Dogs** - Transfer Learning
9.  **09 Stock Price** - Time Series

This order takes you from simplest to most complex.
