# Beginner ML Projects - 10 Projects

All projects run in VSCode, no Kaggle login needed.

## How to run any project
```bash
cd 01-iris-flower-classifier
pip install -r requirements.txt
python main.py
```

## List
1. Iris Flower Classifier - Classification
2. Bangalore House Price - Regression
3. Spam SMS Detector - NLP
4. Titanic Survival - Classic Kaggle
5. Handwritten Digit Recognition - Computer Vision
6. Movie Review Sentiment - Sentiment Analysis
7. Customer Segmentation - Unsupervised K-Means
8. Diabetes Prediction - Medical Binary Classification
9. Stock Price Predictor - Time Series
10. Cats vs Dogs - Transfer Learning (demo + real code)

Each folder has:
- main.py (fully working)
- requirements.txt
- README.md

Tip: Open the root folder `beginner-ml-projects` in VSCode. Use Jupyter extension to run .py as interactive.
